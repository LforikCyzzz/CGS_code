# Group-Shared Low-Rank Approximation for Mobile-Efficient Pointwise Convolutions in Large-Kernel CNNs

This repo is the official implementation of our paper "Group-Shared Low-Rank Approximation for Mobile-Efficient Pointwise Convolutions in Large-Kernel CNNs". 

## Usage

### Train CGS model

To train a CGS model, run:

```bash
bash run_replknet.sh
```
